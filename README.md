# RHCSA Linux Home Lab

A hands-on Linux administration portfolio documenting practical Red Hat Enterprise Linux exercises, configuration management, troubleshooting, and RHCSA preparation.

## About This Repository

This repository documents practical exercises performed in a personal Linux home lab. The objective is to develop strong Linux administration fundamentals through hands-on practice, systematic verification, troubleshooting, and repeatable procedures.

## Lab Environment

- **Operating System:** Red Hat Enterprise Linux (RHEL)
- **Environment:** Personal home lab
- **Learning Approach:** Configure, verify, troubleshoot, document, and repeat

## Documentation Standards

Each completed lab should include:

- Objective and requirements
- Commands and configuration steps
- Explanation of important concepts
- Verification and expected results
- Troubleshooting notes and lessons learned
- Screenshots where useful

## Learning Principles

1. Understand the objective before executing commands.
2. Practise the task in a controlled environment.
3. Verify the result instead of assuming success.
4. Troubleshoot failures systematically.
5. Repeat tasks independently to improve speed and accuracy.

## Certification Goal

This portfolio supports practical preparation for the Red Hat Certified System Administrator (RHCSA) certification.

**Note:** Repository progress reflects personal lab practice and does not itself indicate certification or examination completion.
